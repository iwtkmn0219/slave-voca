## 제안
- **발음기호를 오프라인에서도 구할 방법 (M3 전 검토 권장):** 무료 사전 API가 이번 세션 내내 응답하지 않았다. 지금 카드에는 발음기호가 거의 없다(203개 중 1개). 발음 듣기(Web Speech)는 영향이 없지만, 스펙 성공 기준의 "발음기호(사전에 있으면)"가 사실상 비게 된다. 로컬 발음 사전(예: CMUdict → IPA 변환, 라이선스 확인 필요)을 대안 또는 보조로 두는 것을 제안한다.
- **뜻 생성 묶음 동시 요청 (키를 받은 뒤 측정하고 결정):** 지금은 50개 묶음을 하나씩 순서대로 요청한다. 후보 200개면 4번을 연달아 기다린다. `mapWithConcurrency`로 2~3개씩 동시에 보내면 저장 대기 시간이 줄어든다. 실제 키로 시간을 재 본 뒤 정한다.
- **저장 후 백그라운드 채우기 (M4 후보, PM 기록함):** 저장 즉시 단어 목록으로 이동하고 뜻·발음은 나중에 채우는 방식. "생성 중" 표시와 서버 재시작 시 복구가 함께 필요하다.
- **추출 규칙의 남은 작은 문제 (CodeReviewer Minor, 기록만 함):**
  - 단수형이 아는 단어이면 복수형이 후보로 남는다(`dataset`이 known일 때 `datasets`).
  - 발음 구별 기호가 있는 정상 단어(naïve, café, façade)가 비ASCII 규칙에 걸려 빠진다. 기호를 떼고 판단하면 된다.
  - 복수형 보정이 우연히 같은 짧은 후보와 합쳐질 수 있다(lens → len).

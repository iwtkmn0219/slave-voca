## 계획 밖에서 고친 것 (PM 승인)

- `9f5fff4` CMUdict 강세 기호 위치를 최대 첫소리 원칙으로 바꿨다. 예: abstract `/æbstˈrækt/` → `/æbˈstrækt/`, approach `/əˈproʊtʃ/`, control `/kənˈtroʊl/`. 실제 사전으로 explain `/ɪkˈspleɪn/`, request `/rɪˈkwɛst/`, attribute `/ˈætrəˌbjut/`, constrain `/kənˈstreɪn/`도 확인했다.
- `5d30da6` CMUdict 파일을 읽지 못해도 저장 전체를 오류로 만들지 않는다(null을 주고 로그는 한 번만).
- `24372a2` 응답 버튼을 같은 순간 두 번 눌러도 한 번만 기록한다(위 RF3).

## 제안

- **발음기호 표기 통일 (M4 후보):** 사전 API는 영국식 표기가 섞이고(`/rəʊˈbʌst/`), CMUdict는 미국식이다(`/roʊˈbʌst/`). 발음 듣기가 en-US이니, CMUdict를 먼저 쓰고 사전 API를 보조로 돌리는 순서 변경을 제안한다. 지금처럼 사전 API가 자주 죽는다면 API 조회 자체를 줄이는 효과도 있다.
- **품사에 따라 발음이 다른 단어 (기록만):** CMUdict의 첫 발음만 쓰므로 `record`, `present` 같은 단어는 문맥과 다른 발음기호가 나올 수 있다.
- **응답 실패 후 다시 누르기:** 잠금은 저장이 끝나면(실패 포함) 풀리도록 했지만, 서버 오류 상황을 브라우저에서 재현해 다시 누를 수 있는지는 확인하지 못했다. M4의 오류 메시지 작업 때 함께 확인하면 좋겠다.
- **실제 소리 확인:** 발음 듣기는 호출까지만 확인했다. 사용자가 처음 쓸 때 소리가 나는지 한 번 봐 주면 된다.

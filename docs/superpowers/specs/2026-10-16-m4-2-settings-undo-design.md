# M4-2 설계: 설정 화면, 직전 응답 되돌리기, 발음 자동 재생, 검토 문장 줄이기

- 상태: 사용자와 대화로 합의, 승인(2026-10-16). 프로토타입과 Designer 검수를 거쳐 3.3(테마 저장)을 고쳤다. 계획서: `docs/superpowers/plans/2026-10-16-m4-2-settings-undo.md`
- 상위 설계서: `2026-10-13-slave-voca-design.md` 11장 M4. UI 개편안: `2026-10-15-ui-redesign.md` 5장(설정 `/settings`), 9장(5·6·7번).

## 1. 목적과 범위

M4-1로 뜻을 믿고 복습할 수 있게 됐다. M4-2는 매일 쓰기 편하게 만든다.

1. 직전 응답 되돌리기(`Z`): 잘못 누른 응답을 바로 고친다.
2. 설정 화면: 흔한 단어 제외 기준 N, 하루 새 카드 수, 화면 테마, 발음 자동 재생.
3. 뒷면을 열 때 발음 자동 재생(설정으로 켠다).
4. 검토 표 문장 줄이기(Designer 조건, 상위 설계서 11장).

뺀 것: "오류 메시지 정리"(무엇을 고칠지 정해진 것이 없다. 필요한 항목이 생기면 따로 잡는다), 앞면 문맥 힌트 옵션(개편안 9장 4번, 사용자 결정 필요).

화면의 모양(버튼 위치, 입력 형태, 안내 문구)은 Designer가 정한다. 이 문서는 동작만 정한다.

## 2. 직전 응답 되돌리기

### 2.1 범위(사용자 결정: A안)

- **이번 복습 세션에서 마지막 응답 한 번만** 되돌린다. 되돌린 뒤 또 되돌릴 수 없고, 페이지를 새로 열면 되돌릴 대상이 없다.
- 완료 화면에서도 마지막 한 장을 되돌릴 수 있다.

### 2.2 저장(사용자 결정: 1안)

- `review_logs`에 `prev_card`(text, null 허용) 열을 더한다(마이그레이션 0004). 응답을 저장할 때 **응답 전** 카드의 일정 상태를 JSON으로 넣는다: `due`, `stability`, `difficulty`, `elapsedDays`, `scheduledDays`, `learningSteps`, `reps`, `lapses`, `state`, `lastReview`, `introducedAt`.
- 마이그레이션 전에 쌓인 기록은 `prev_card`가 null이며 되돌릴 수 없다(세션 안에서만 되돌리므로 실제로 생기지 않는다).

### 2.3 동작

- `recordAnswer`는 새 기록의 id를 함께 돌려준다. 화면은 직전 응답 하나(기록 id, 카드, 응답 종류)만 기억한다.
- 되돌리기 요청(기록 id)을 받으면 서버는 한 트랜잭션에서:
  1. 기록이 있고 `prev_card`가 있는지 본다.
  2. 그 기록이 **그 카드의 가장 최근 기록**인지 본다. 아니면 거부한다(다른 탭에서 또 응답한 경우).
  3. 카드 상태를 `prev_card`로 복구하고(새 카드였다면 `introducedAt`이 null로 돌아가 하루 새 카드 수가 다시 하나 늘어난다) 기록을 지운다.
- 화면: 그 카드가 큐 맨 앞에 **앞면**으로 다시 나온다. 답한 수가 하나 줄고, "모름"이었다면 모름 수도 하나 준다. 완료 화면의 "곧 다시 나옴" 계산에서도 그 카드를 뺀다. 메뉴 배지를 다시 그린다.
- 단축키 `Z`. 입력칸에서는 끈다(기존 규칙). 처리 중 두 번 눌러도 한 번만 실행된다.
- 거부되거나 실패하면 짧은 안내를 보여 주고 큐는 그대로 둔다.

## 3. 설정 화면

### 3.1 항목

| 항목 | 키 | 값 | 처음 값 | 적용 |
|---|---|---|---|---|
| 흔한 단어 제외 기준 N | `exclude_top_n` | 1,000~20,000 정수 | 5,000 | 그 뒤에 올리는 문서부터. 이미 뽑은 후보와 카드는 그대로(화면에 한 줄로 알린다) |
| 하루 새 카드 수 | `daily_new_limit` | 0~200 정수 | 20 | 바로(홈, 메뉴 배지, 복습). 0이면 새 카드 없이 복습만 |
| 화면 테마 | 쿠키 `theme` | `system` / `light` / `dark` | `system` | 저장하면 바로 |
| 발음 자동 재생 | `auto_speak` | 켜기 / 끄기 | 끄기(사용자 결정) | 다음에 뒷면을 열 때부터 |

N의 위 한계는 빈도 목록 길이(20,349단어)에 맞춘다.

### 3.2 동작

- 경로 `/settings`. 상단 바 오른쪽 끝에 "설정"(개편안 5장).
- 저장 버튼 하나로 네 항목을 함께 저장한다. 서버가 항목마다 범위를 확인하고, 하나라도 벗어나면 아무것도 저장하지 않고 그 항목에 오류를 보여 준다.
- 저장되면 "저장했습니다"를 보여 주고 레이아웃 전체를 다시 그린다(테마, 배지).
- 읽을 때 DB 값이 없거나 잘못됐으면 처음 값을 쓴다(지금과 같음). 단 하루 새 카드 수 0은 올바른 값이다(지금은 0을 처음 값으로 바꾼다).

### 3.3 테마 적용(사용자 결정 2026-10-16: 쿠키)

- 테마만 **쿠키**(`theme`, 1년, `SameSite=Lax`)에 둔다. 나머지 세 항목은 DB `settings` 테이블이다.
- 이유: 레이아웃은 부분 사전 렌더링(정적 셸)이다. 레이아웃이 DB나 쿠키를 서버에서 읽으면 앱 전체가 요청마다 그려진다(Next 문서 "Preventing flash before hydration", "Migrating to Cache Components"). 그래서 `<head>`의 인라인 스크립트가 HTML을 읽는 중에 쿠키를 보고 `<html data-theme>`를 붙인다. 첫 화면이 그려지기 전이라 번쩍임이 없고, 정적 셸도 그대로다(프로토타입 빌드에서 모든 페이지가 ◐ 유지).
- `system`이면 쿠키를 지우고 속성도 없다(OS 설정을 따른다). `light`·`dark`면 쿠키에 저장한다. 저장한 화면에서는 클라이언트가 속성을 바로 바꾼다.
- 개발 모드의 Strict Mode 재마운트가 `<html>` 속성을 지우므로, 작은 클라이언트 컴포넌트가 `useLayoutEffect`로 쿠키에서 다시 적용한다.
- 쿠키는 브라우저마다 따로다. 혼자 한 컴퓨터에서 쓰는 앱이라 받아들인다.

## 4. 발음 자동 재생

- `auto_speak`가 켜져 있으면 뒷면을 열 때(Space, Enter, "뒷면 보기" 버튼) 단어를 한 번 읽는다. 기존 `speak`를 쓴다.
- 브라우저가 음성을 지원하지 않으면 조용히 넘어간다. `P`와 스피커 버튼은 그대로다.

## 5. 검토 표 문장 줄이기

상위 설계서 11장의 Designer 조건 그대로다.

1. 140자 안팎, 1280px에서 최대 2줄.
2. 가장 가까운 공백에서 자른다. 화면용 함수(`lib/text/truncate.ts`의 `cutAround`, `shortSentence`)를 따로 둔다. 저장용 300자 자르기(`extract.ts`의 `truncateAround`)는 바꾸지 않는다(새 문서의 저장 결과가 달라지지 않게).
3. 포커스 행을 펼치지 않는다. 전체 문장은 문장 칸 `title`로.
4. 자르는 기준은 `Highlighted`와 같은 첫 일치.

저장된 원문(300자)은 바꾸지 않는다. 검토 표에서만 표시용으로 자른다.

## 6. 화면(Designer 2026-10-16)

- 되돌리기: 답 버튼 아래 단축키 안내 줄("[P] 발음 듣기")에 "· [Z] 되돌리기 단어 · 응답"을 붙인다(줄의 세로 위치가 변하지 않음). 버튼은 점선 밑줄, 응답 이름은 응답 색. 처리 중에는 스피너 없이 disabled, 1·2·3·Space·Enter·Z 무시. 되돌린 뒤 "단어 응답을 되돌렸습니다", 거부 "되돌리지 못했습니다 · 다른 곳에서 이미 답한 카드입니다"(대상 지움), 그 밖의 실패 "되돌리지 못했습니다"(대상 남김). 다음 응답에 문구가 사라진다. 완료 화면은 "홈으로" 아래 "[Z] 마지막 응답 되돌리기".
- 설정: 760px 폭, 묶음 제목 "단어 추출 / 복습 / 화면", 2열 행, 숫자 칸 120px(증감 화살표 없음), 자동 재생·테마는 Segmented(라디오 그룹). 오류는 칸 테두리(포커스 중에도 유지)와 칸 아래 문구, 버튼 옆 "저장하지 않았습니다 · 표시한 항목을 고쳐 주세요", 첫 오류 칸으로 포커스. 성공은 "저장했습니다"(입력을 바꾸면 사라짐). 상단 바 오른쪽 끝 "설정".
- Segmented를 공용 부품으로 만들고 업로드의 논문/발표 선택도 이것을 쓴다.

## 7. 테스트

- 되돌리기: 응답 → 되돌리기로 카드 상태와 기록 수가 응답 전과 같아진다. 새 카드의 `introducedAt`과 하루 새 카드 수가 돌아온다. 최신 기록이 아니면 거부한다. `prev_card`가 없으면 거부한다. 같은 기록을 두 번 되돌릴 수 없다.
- 설정: 범위 안·밖 값, 0인 하루 새 카드 수, 잘못된 DB 값의 처음 값 대체, 일부만 틀린 입력은 아무것도 저장하지 않음.
- 문장 줄이기: 길이, 공백 경계, 첫 일치가 잘리지 않음.
- 브라우저: 되돌리기(Z·버튼, 진행 수·모름 수·배지), 설정 저장 후 테마 즉시 적용과 첫 화면 번쩍임 없음, 자동 재생 켜고 끄기, 하루 새 카드 0, 검토 표 2줄.
- 실제 Gemini 호출은 없다.

## 1. 단어 추출 정확도(M2 리뷰에서 넘어온 항목)

### 1.1 원인(프로토타입에서 확인)

- 원형 처리기(wink)가 신조어 복수형을 바꾸지 못한다: `datasets`, `logits`, `hyperparameters`, `perceptrons`, `embeddings`, `params`.
- 이를 메우던 `mergePlurals`는 **같은 문서의 후보끼리만** 합쳤다. 그래서 단수형이 아는 단어라 후보에서 빠지면 복수형이 혼자 남았다.
- 같은 함수가 끝의 s만 보고 합쳐서, 문서에 `len`(코드)이 후보로 있으면 `lens`가 `len`으로 합쳐졌다.
- 발음 구별 기호가 있는 단어(`naïve`, `café`)는 ASCII가 아니라는 이유로 통째로 버려졌다. 형광펜의 단어 경계(`\b`)도 ASCII 기준이라 `ï`를 경계로 잘못 봤다.

### 1.2 규칙

1. **복수형은 단어마다 처리한다.** 원형 처리기가 형태를 바꾸지 못한 단어가 다음을 모두 만족하면 끝의 s를 뗀 단수형을 원형으로 쓴다. 문서 단위 합치기(`mergePlurals`)는 없앤다.
   - s로 끝나고, -ss·-us·-is로 끝나지 않는다(glass, softplus, axis는 그대로).
   - 그 형태가 사전(WordNet)에 없다(lens, bias, series, analysis는 그대로).
   - s를 뗀 길이가 3자 이상이다.
   - 그 형태는 빈도표에 있는데 s를 뗀 형태는 빈도표에 없는 경우가 아니다(whereas는 그대로. wherea는 단어가 아니고, 학술어 예외도 whereas로 받아야 한다).
2. 단수형으로 바꾼 뒤에 원래 규칙(빈도 순위, 아는 단어, 학술어 예외)을 적용한다. 그래서 단수형이 아는 단어거나 흔한 단어면 복수형도 함께 빠진다(ours → our는 흔한 단어라 빠진다).
3. **발음 구별 기호:** 문장을 NFC로 모은 뒤(조합형 i + ̈ 를 한 글자로), 토큰에서 기호를 떼어(NFD 후 결합 문자 제거) 원형을 만든다. 떼어도 ASCII가 아니면(Łukasz) 지금처럼 버린다. 표면형(surface)은 문장에 적힌 그대로(naïve) 둔다.
4. **형광펜과 첫 일치:** 단어 경계를 `\b` 대신 앞뒤 글자 검사(`\p{L}\p{N}_`가 아닌 곳)로 본다. naïve, Naïve는 표시하고 naïveté 안의 naïve는 표시하지 않는다.

### 1.3 영향

- 이미 저장된 후보와 카드는 바뀌지 않는다. 새로 올리는 문서부터 적용된다.
- 논문 3편 비교(빈 단어장, N=5000): ResNet 229 → 229, Attention 241 → 240, BERT 215 → 215. 바뀐 것은 `params`→`param`, `perceptrons`→`perceptron`, `embeddings`→`embedding`, `hyperparameters`→`hyperparameter`, 그리고 `ours`가 빠진 것뿐이다. 나머지 후보와 횟수는 같다.

## 2. M4-2 리뷰의 작은 문제 5건

1. 되돌리기가 일시적으로 실패하면(네트워크 등, 대상이 남아 있을 때) "되돌리지 못했습니다" 옆에 "다시 시도" 버튼을 둔다(Z와 같은 동작. 다시 만들기 결과 표시와 같은 규칙).
2. 저장·되돌리기 처리 중에는 뒷면 열기(버튼 클릭 포함)와 자동 재생을 하지 않는다.
3. 설정을 저장하는 동안 입력을 바꾸면, 그 값은 저장되지 않았으므로 "저장했습니다"를 띄우지 않는다.
4. DB의 숫자 설정이 숫자가 아니면(빈 문자열 포함) 처음 값으로 읽는다(`Number('')`가 0이던 문제).
5. 검토 표 문장 줄이기는 길이 제한이 단어 길이에 가까워도 단어를 통째로 남긴다(그만큼 제한을 조금 넘을 수 있다).

## 3. 다크 토큰 정리(UI 개편 리뷰에서 넘어온 항목)

- 같은 다크 색 22개가 `globals.css`에 두 번(시스템 다크 미디어 쿼리, `data-theme="dark"`) 적혀 있었다.
- 각 색을 CSS `light-dark(라이트, 다크)`로 한 번만 적는다. 어느 쪽을 쓸지는 `color-scheme`이 정한다: `:root`는 `light dark`(OS 설정), `data-theme="light"`·`"dark"`는 각각 하나로 고정.
- 그림자는 테마마다 모양이 달라 쓰지 않는 쪽 층을 투명으로 둔다(라이트 2층, 다크 1층).
- Tailwind의 Lightning CSS가 `light-dark()`를 오래된 브라우저용 변수로 바꿔 내보낸다. 동작은 같다.
- **바뀌는 화면이 없어야 한다.** 프로토타입에서 5개 화면 × 3모드(라이트 쿠키, 다크 쿠키, 시스템 다크) 15장이 정리 전후로 바이트까지 같았다.
